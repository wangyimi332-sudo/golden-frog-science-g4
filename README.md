# California Science Grade 4 · Golden Frog Science Island Grade 4 黄金蛙科学探险岛

G4 把黄金蛙探险升级为一次次小型科学研究。七章共 84 关，每章 12 关；孩子先改变模型或比较条件，再从结果中选证据，最后拼接英文解释。课程把旧概念安排到后续章节重新出现，让生物、地球和物理主题之间逐渐建立联系，而不是每章学完就放下。

## 取材与创作

依据 Macmillan/McGraw-Hill 2008 年版《California Science Grade 4》主教材的 7 章、24 课目录和科学概念编写原创伴学任务。主教材是本版的主要取材依据；网页不提供教材原页、原题或原插图。

## 全册章节

- 第 1 章 生物需要能量｜从阳光、植物制造食物进入食物链、食物网和微生物，追踪能量怎样在生物间传递。
- 第 2 章 生物与环境｜研究生态系统、生物相互依赖、环境变化和适应，比较生物记录与环境条件。
- 第 3 章 岩石与矿物｜依据矿物性质识别证据，比较火成岩、沉积岩和变质岩及其形成线索。
- 第 4 章 地球的缓慢变化｜区分风化、侵蚀和沉积，借助河流与地貌模型解释长期变化。
- 第 5 章 地球的快速变化｜研究滑坡、地震与火山的迹象和影响，明确教学模型不能预测真实灾害。
- 第 6 章 电｜比较静电、闭合电路和电能用途，通过搭建与排错解释电流路径及能量输出。
- 第 7 章 磁｜研究磁铁、电磁铁、电动机和发电机，回访电路与变量控制，解释电和磁怎样协作。

## 学习方式

84 关全部开放。每关按“操作模型—观察或读记录—判断证据—拼接英语句子”推进，模型主题共 28 组。英文大标题和自然研究基地配合中文辅助；Heart、Bella 双声线、慢速重听及可见文字支持不同学习节奏。

## 综合复习

螺旋复习穿插在本章后段和后续章节：例如用 G3 的生境知识解释食物网，用岩石证据研究侵蚀，再把控制变量用于电路和电磁铁。Grow 提供已完成关卡的回访入口、首次推理记录及分章研究手账。复习的目标是比较前后解释质量，检验能否在不同材料中重新使用同一思维方法。

## 期末检查与学习评估

现版以每关的操作、证据选择、英语句子及章末研究任务作阶段性检查，并记录首次正确推理。网站没有独立的全册期末试卷；不能将 84 关的完成数量直接当作科学或英语等级成绩。

## 成长模块与家庭学习

Explore、Research Base、Discover 和 Grow 把章节任务、研究基地、发现记录和自由回访连接起来。孩子与家长档案独立，支持导出、导入；重玩旧关卡时可以补写更有证据的解释。

## 培养的能力

着重培养模型操作、读图读表、比较快慢变化、控制变量、排查电路问题、判断证据是否充分，以及用较完整英语句子表达因果关系和模型局限。
